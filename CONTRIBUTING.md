# Contributing

Contributions are welcome.

Useful contributions include:

- improvements to the mother template;
- better source-scope conventions;
- runtime-governance research;
- audit methods;
- alternative schemas;
- translations;
- host/orchestrator tools;
- documentation.

The first release intentionally keeps concrete Lens examples outside the core repository.

If you contribute a Lens later, clearly document its source scope and avoid claiming doctrinal completeness.
